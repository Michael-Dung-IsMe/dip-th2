## Thứ tự đọc và đối chiếu

1. Đọc [tổng quan](resources/TONG_QUAN_THUC_HANH_2.md) và [danh sách ảnh](resources/DANH_SACH_ANH_THUC_HANH.md).
2. Xem kế hoạch tương ứng trong [`planning/`](planning/) trước khi chạy từng notebook.
3. Đối chiếu kết quả với [báo cáo Markdown](BAO_CAO_THUC_HANH_2.md). Mỗi bài có phần ảnh minh chứng ở cuối bài.
4. Xuất lại [báo cáo PDF](BAO_CAO_THUC_HANH_2.pdf) sau khi sửa Markdown để hai bản thống nhất.

Mã thực nghiệm nằm trong [`../notebooks/`](../notebooks/), ảnh đầu vào ở [`../data/`](../data/), kết quả xử lý và ảnh chụp màn hình VS Code ở [`../outputs/`](../outputs/) và [`../outputs/screenshots/`](../outputs/screenshots/). Các ảnh chụp minh chứng được nhúng bằng đường dẫn tương đối trong báo cáo Markdown.
